# /admin — закрытый раздел

Личные рабочие инструменты. Ссылок с сайта нет, `robots.txt` закрывает `/admin/`, страницы с `noindex`.

- `index.html` — список проектов. Вход по паролю: пароль хешируется (SHA-256) в браузере и уходит
  заголовком `x-budget-key` в Supabase, где RLS сравнивает его с хешем в политике. Сам пароль
  нигде не хранится, хеш лежит в `localStorage.admin_key`.
- `config.js` — URL проекта Supabase и publishable-ключ (рассчитан на браузер, данные защищены RLS).
- `projects/budget/` — планер бюджета. Одна страница без сборки, Chart.js с cdnjs. Данные: одна
  строка `budget_state.data` (jsonb), история версий в `budget_history` через триггер.
  `?local=1` — локальный режим на localStorage без базы (для отладки и офлайна).

Данные в репозиторий не кладутся никогда: репо `danilakruzhkov-arch.github.io` публичный.
